# 💈 Projeto Barbearia

## 📌 Sobre o projeto

O **Projeto Barbearia** é uma aplicação web desenvolvida durante o 2º período da graduação em Ciência da Computação, com o objetivo de criar uma plataforma digital para uma barbearia.

O sistema permite que os usuários conheçam o estabelecimento, visualizem os serviços oferecidos, consultem seus respectivos preços e realizem agendamentos on-line.

O projeto foi desenvolvido como parte do aprendizado acadêmico, proporcionando experiência prática com desenvolvimento web, programação back-end e integração com banco de dados.

## 🚀 Funcionalidades

* **Apresentação da barbearia:** página com informações sobre o estabelecimento.
* **Consulta de serviços:** visualização dos serviços disponíveis e seus respectivos preços.
* **Agendamento on-line:** formulário para selecionar o serviço, a data e o horário desejados.
* **Verificação de disponibilidade:** consulta de horários ocupados para auxiliar na escolha do agendamento.
* **Gerenciamento de reservas:** funcionalidades para consultar e realizar operações relacionadas aos agendamentos.

## 🛠️ Tecnologias utilizadas

* **HTML5:** estruturação das páginas.
* **CSS3:** estilização e organização visual da interface.
* **JavaScript:** implementação de interações e funcionalidades no front-end.
* **PHP:** processamento de formulários e regras de negócio no back-end.
* **SQL:** linguagem utilizada para consultas e manipulação dos dados.
* **MySQL:** sistema de gerenciamento de banco de dados.

## 🎯 Objetivos de aprendizagem

O desenvolvimento deste projeto contribuiu para a aplicação prática de conhecimentos relacionados a:

* Desenvolvimento de interfaces web.
* Programação back-end com PHP.
* Manipulação e persistência de dados.
* Integração entre aplicação web e banco de dados.
* Criação de formulários e fluxos de agendamento.
